# אתר אישורי הגעה לחתונה 💍

אפליקציית RSVP בעברית (RTL): כל בית אב מקבל קישור אישי (`?g=TOKEN`) עם
שמו, 3 שאלות (מגיע? / כמה? / לינה?) ורשימת ציוד למי שנשאר לישון.
דף הניהול (`/admin`) מציג סיכומים חיים, טבלה, ייבוא Excel חכם
וכפתורי שליחה בוואטסאפ.

## הרצה מקומית

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

- עמוד אורח: http://127.0.0.1:5000/?g=TOKEN
- דשבורד: http://127.0.0.1:5000/admin

## פריסה חינמית (Render)

1. העלו את התיקייה לריפו ב-GitHub.
2. ב-Render: New → Web Service → בחרו את הריפו.
3. Build: `pip install -r requirements.txt`, Start: `gunicorn app:app --bind 0.0.0.0:$PORT`.
4. הקישור הציבורי שתקבלו הוא בסיס הקישורים לאורחים.

שימו לב: בתוכנית החינמית של Render, הדיסק אינו קבוע לאורך זמן —
לחתונה חד-פעמית זה בדרך כלל מספיק, אבל לגיבוי מומלץ לייצא CSV
מהדשבורד מדי פעם. לחלופין, חברו בסיס Postgres והחליפו את `DB_PATH`.

## שליחה אוטומטית בוואטסאפ

ברירת המחדל: כפתורי wa.me — פותחים וואטסאפ עם הודעה מוכנה
(שם + קישור אישי), ולחיצה אחת על "שלח".

לשליחה אוטומטית מלאה: חברו בדשבורד (הגדרות → חיבור שירות שליחה)
שירות gateway כמו WAHA / Evolution API / Ultramsg — השרת ישלח
ישירות דרך ה-API שלו. פרטים והשוואת ספקים: ראו את המחקר המצורף.
